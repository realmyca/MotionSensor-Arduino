# Pritchard menu bridge

This folder is a small bridge for the UBC Okanagan Pritchard Dining Hall Nutrislice menu.

- `fetch_menu.py` fetches the public Nutrislice JSON API for the current date in `America/Vancouver`.
- `current.json` is generated by GitHub Actions and contains simplified breakfast, lunch, and dinner data.
- The workflow refreshes the file every 30 minutes and can also be run manually.

Public raw JSON:
`https://raw.githubusercontent.com/realmyca/MotionSensor-Arduino/main/pritchard-menu/current.json`

The bridge is unofficial and is not affiliated with UBC or Nutrislice.
